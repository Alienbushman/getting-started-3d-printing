---
term: "STL"
definition: "Standard Triangle Language (or STereoLithography) — the most common 3D model file format for printing. An STL describes only the surface geometry of a shape as a mesh of triangles. It contains no colour, material, or unit information."
see_also: ["3mf", "slicer"]
gotcha: "STL files have no built-in unit — a model designed in millimetres might import at a different scale if the slicer assumes inches. Check model dimensions in the slicer before printing."
---
